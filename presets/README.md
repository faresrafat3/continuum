# Preset source archive

These files mirror the user-authored DSH presets installed at:

- `~/.dsh/.agent-presets/continuum/`
- `~/.dsh/.agent-presets/continuum-curator/`

They are included in the project checkpoint for review and recovery. The live roster paths remain the `~/.dsh/.agent-presets/` copies; do not edit the shipped `standard`/`cordis` installations.

The presets contain the Continuum and Continuum Curator personas, progressive-disclosure skills, and the agent contract files. The dynamic Host package is separate and process-local; its source is under `plugins/`.
