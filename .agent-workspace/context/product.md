# Product context

Continuum is a DSH-native context and continuity layer. It helps a human keep a clean working context while preserving evidence, lineage, and safe recovery across fresh sessions.

The first supported user outcomes are:

- classify a task and choose a route;
- research with primary-source claims and a decision matrix;
- hand unfinished or valuable work to a new Session in the same workspace;
- organize a workspace with a small WCS coordination plane;
- preview reversible Session fork/archive actions without touching the Host system.

The first release does not physically delete session logs, change model defaults, or automatically archive sessions.
